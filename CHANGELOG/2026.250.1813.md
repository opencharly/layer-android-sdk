# 2026.250.1813 — fix: point the aapt2 check at the build-tools 36.0.0 install path

## Summary

The android-emulator check beds (check-android-emulator-pod, and every layer that
inherits this probe) fail their image-scope gate on this step:

    FAIL  check build-tools 36 provides aapt2 (Appium's ADB badging probe needs it)
          [plan:candy:github.com/opencharly/layer-android-sdk:3]  exists=false, want true

The check probes `/opt/android-sdk/build-tools/36/aapt2`, but the AUR
`android-sdk-build-tools-36` package installs build-tools under the full
versioned directory `/opt/android-sdk/build-tools/36.0.0/`. This is a
layer-internal inconsistency: the layer's own install cannot satisfy its own
check, so every android-emulator bed (adb + appium waves) was red at
check-image. The check now probes `/opt/android-sdk/build-tools/36.0.0/aapt2`.
